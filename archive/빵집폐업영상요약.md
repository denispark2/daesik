# 빵집 폐업 영상 4개 — 폐업 이유·분석 요약 (박대식)

작성 2026-11-17 · 근거: 각 영상 자막(자동 자막 포함, 오타 많음) · 메타 정보는 같은 폴더 video- 파일 참고
- 숫자는 **영상에서 말한 값**이고 원자료를 따로 확인하지 않음. 영상끼리 다른 숫자는 4번에 따로 적음

## 1. 하루 10곳씩 문 닫는다... 대한민국 동네 빵집이 사라지는 이유 (투자한잔, 2026-11-14)
video-bakery-closure-reasons.md · YouTube 표시 "AI로 제작"

**폐업 이유**
1. **빵값은 올랐는데 남는 돈이 적음**: 1만 원 팔면 남는 돈 약 630원 (공정위 보고서 인용 보도, 2:37). 치킨집·카페보다 적음
2. **미리 만들어야 하는 구조**: 손님 수를 모르고 아침에 구움 → 적게 만들면 품절, 많이 만들면 남음. 당일 판매 빵은 다음 날 팔기 어려워 재료비·인건비를 못 건짐 (2:57~3:40)
3. **비용 3중 부담**: 원재료비·임대료·인건비. 국제 밀값은 2022년 고점의 절반으로 내렸지만 버터·달걀·설탕·운반비 때문에 빵값은 안 내려감
4. **천원빵집**: 1,000원으로 손님은 모았지만 남는 게 없어 값을 올림 → 매출 절반 → 두 달 만에 폐업 (국민일보 보도 인용)
5. **경쟁**: 2000년대 대형 체인 확장 → 개인 빵집 약 18,000곳(2000년대 초) → 4천여 곳(2011년 말). 출점 제한(500m, 연 2%)은 2024-08에 400m·5%로 완화, 2029년까지
6. **편의점 빵**: 2026년 상반기 주요 편의점 3곳 빵 매출 +20.1%. 다만 영상도 "손님이 얼마나 옮겨갔는지는 알 수 없다"고 말함
7. **가맹점도 어려움**: 파리바게뜨 가맹점 평균 매출 2022년 7억 5,474만 원 → 2년 뒤 약 5천만 원 감소. 2024년 신규 52곳 vs 점주 변경 237건. 창업비 30평 2억 3,800만~2억 7,700만 원. 계열 공장 사고 불매 때 가맹점 매출 25~45% 감소
8. **버티다 빚만 쌓임**: 화성 빵집 사장 사례

**분석 숫자**: 폐업 2024년 3,593곳(20년 사이 최다), 2025년 3,500곳 넘음. 폐업률 2020년 11.1% → 2024년 18.5%. 1년 넘게 영업한 곳만 봐도 증가. 두 대형 체인이 아닌 빵집은 2024년 23.1% 폐업

**결론(영상)**: 빵을 잘 만드는 것만으로는 부족하고, 손님이 계속 찾아올 이유를 만들어야 함. 사장은 "얼마나 만들고 무엇을 팔지" 계속 계산해야 함

## 2. 제빵사도 안됩니다. 베이커리 카페 창업은 절대 하지 마세요. (자영업마케팅, 빌드업CEO, 2024-12-17)
video-bakery-cafe-startup-risks.md · 베이커리 카페와 공장을 운영해 본 사람의 경험담 (통계 근거 없음)

**어려운 이유 4가지**
1. **규모**: 빵집은 포장 위주라 작아도 되지만, 베이커리 카페는 먹고 가는 곳이라 회전율이 낮음 → 크게 해야 함. 50평도 설비·진열·커피 공간 빼면 테이블이 적음 → 임대료 부담 → 외곽으로 밀려남
2. **인력**: 빵 매출이 제빵사 급여의 3~4배는 돼야 운영됨. 주 5일 근무라 제빵사 2명 필요 → 급여 2배. 생지(냉동 반죽)는 **폐기까지 계산하면** 원가가 높고 빵에 특징이 없어 매출이 떨어짐
3. **창업비**: 데크 오븐(500만~680만 원대)·반죽기·냉동고·작업대 + 전기 공사·인테리어·창고 → 실패하면 손실이 큼
4. **양도 어려움**: 시설비가 높아 권리금이 높고, 기술·레시피를 넘기기 어려워 가게를 팔기 힘듦

**결론(영상)**: 자본을 늘리고 나만의 빵이 있어야 함. 차라리 디저트 카페를 권함. 하고 싶다면 빵 하는 카페에서 먼저 일해 보라고 함

## 3. 동네 빵집의 몰락 하루 10곳씩 사라지는 충격적인 이유 (이부장 경제톡, 2026-03-06)
video-neighborhood-bakery-decline.md · 구독자 41명 채널, 출처 표시 없음 → 숫자 신뢰도 낮음

**폐업 이유 ("삼중 함정")**
1. **원재료값**: 밀가루·설탕·버터 거의 수입. 2022년 우크라이나 전쟁 때 오른 값이 안 내려옴. **2026-02 검찰이 밀가루·설탕 담합 적발**, 밀가루 5조 9,913억 원 + 설탕 3조 2,715억 원이라고 함 → **미확인**
2. **인건비**: 빵 원가에서 밀가루는 20~30%, 나머지는 인건비·임대료·전기 같은 고정비. 인건비 비중 28.7%라는 연구가 있다고 함(출처 안 밝힘). 최저임금 상승 → 직원 내보내고 혼자 일함
3. **대형 가맹점**: 통신사 할인·행사를 못 따라감. 가맹점 하나 들어오자 동네 빵집이 전부 닫았다는 방송 사례
4. **편의점 빵**: 편의점 한 곳 차별화 빵 매출 2026-01 +30.5%. 소금빵 3,500원 vs 편의점 1,500원

**분석**: 빵값 5년 사이 40% 가까이 상승인데도 망하는 역설. 서울 2024년 폐업 1,179곳, 평균 영업 8.8년. 유행 혜택은 유명 빵집에만 → 양극화 (성심당 영업이익 478억 원, 부산 빵집 연매출 210억 원 사례)

**결론(영상)**: 출점 제한 규제는 효과가 의문. 살아남은 곳은 공동 제품 개발·공동 구매로 재료비를 낮추고, 동네만의 이야기가 있는 빵을 만듦

## 4. '매출 2천억' 성심당 다른 빵집들은 줄줄이 폐업 #핫픽뉴스 (KBC 뉴스, 2025-04-28)
video-sungsimdang-bakery-closures.md · 2분 30초 뉴스

**폐업 이유**: 빵지순례 열풍이 식음. 원재료비·임대료·인건비 부담이 겹쳐 중소 제과점 수익성 악화 (업계 관계자)
**분석 숫자**
- 2024년 폐업 빵집 3,591곳 (지방행정 인허가 데이터, 최근 5년 최대). 2020년 이후 매년 2,000곳 넘게 폐업
- 폐업률 2020년 11.1% → 2022년 13.8% → 2023년 15.9% → 2024년 18.5%
- 유명 빵집도 매출 감소: 옵스 299억 원(−2.2%), 삼송빵집 180억 원(−4.5%), 노티드 630억 원(−6.7%)
- 반대로 성장: 성심당 1,987억 원(+55.8%), 뚜쥬루 253억 원(+126%, 체험형 관광 '빵돌가마 마을')

**결론(영상)**: 프랜차이즈·전통 빵집과 다른 콘텐츠로 단골을 확보하는 게 가장 중요
