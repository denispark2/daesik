## 1. 김서연 pain point Top3

팀 투표 Top3(`journey/pain-top3.md`)를 그대로 따름.

| 순위 | ID | 단계 | pain point | 근거 |
|---|---|---|---|---|
| 1 | M2-1 | 2 찾아봄·막힘 | 후기가 너무 많아 다 읽고 고를 수 없음 | ACC 플레이스 블로그 후기 10,369개 (README) |
| 2 | M2-3 | 2 찾아봄·막힘 | 같은 전시 정보가 여러 글에 흩어져 있음 | 인상파 후기 B32·B37, 후기마다 전시 이름·정보가 다름 |
| 3 | M6-3 | 6 관람 | 작품 수가 적음 · 작품 선정이 기대와 다름 | B37·N7. 인상파 "작품 수가 적어 금방 끝난다" 15개 글 (`ACC현재전시_블로그리뷰취합.md` 2-1) |

### 1) M2-1 후기가 너무 많아 고를 수 없음
- **이미 있는 해결책**: README 전시 추천 페이지 — 리뷰 수, 한 줄 요약(좋은 점 2 + 아쉬운 점 1), 원문 링크
- **아이디어**
  1. **"나 같은 사람 후기"만 먼저 보여주기** (제안): 입력한 동행·취향과 같은 후기를 앞에 둠. 예) 혼자 + 사진 취향이면 "혼자 왔다"·"사진" 언급 후기 우선. 1만 개를 다 요약하는 것보다 서연이 믿을 만한 3개가 더 쓸모 있음
  2. **숫자 한 줄로 끝내기** (제안): "후기 232개 중 사진·포토존 40%, 붐빔 언급 많음"처럼 비율 한 줄. 키워드 비율은 이미 `ACC현재전시_대표키워드.md`에 있음
  3. **결정을 대신 내려주기**: 서연은 후기를 여러 개 보고도 마지막에 망설이는 성격(ENFP). 후보를 여러 개 보여주지 말고 **1개를 고르고 "왜 이 전시인지" 한 줄**을 붙임 (예: "사진 잘 나오는 곳을 골라서 → 포토존 후기 40%")

### 2) M2-3 같은 전시 정보가 흩어져 있음
- **아이디어**
  1. **전시 이름 하나로 묶기**: 후기마다 전시 이름이 다름 → `exhibition-list.전시명` 기준으로 맞춰서 한 카드에 모음 (팀 체크리스트 B와 같음). 별명·줄임말 사전을 만들어 자동으로 묶음 (예: "인상파전", "모네전" → 인상파, 찬란한 순간들)
  2. **지금 하는 전시만 보여주기**: 서연의 막힘 중 하나가 "어떤 후기가 지금 하는 전시인지 구분이 안 됨". 종료된 전시 후기, 리뉴얼 전 내용 후기는 카드에서 빼거나 표시 (리뉴얼 구분 규칙은 박대식 메모리 규칙과 같음)
  3. **흩어진 실용 정보를 카드 한 장에**: 장소(관·층), 무료/유료, 정각 시작(김영은), 줄 서는 곳(인상파 포토존), 예약 필요 여부를 후기에서 뽑아 카드에 고정 칸으로 둠. 예상 리뷰 4개 모두에서 "미리 알려줬으면" 불만이 나옴

### 3) M6-3 작품 수가 적음 · 기대와 다름
- **아이디어**
  1. **기대치 카드에 '규모'를 넣기** (제안): "회화 21점, 금방 끝난다는 후기 있음"처럼 크기를 미리 알려줌. 실망은 작품 수보다 기대와의 차이에서 생김
  2. **취향에 '사진·분위기' 추가** (제안): 지금 취향 4개(명화·체험·미디어·역사)에는 서연이 원하는 "사진 잘 나오는 곳"이 없음. `김서연_예상리뷰.md`에서 김영은(사진 3%)이 추천돼 불만이 남. 사진·포토존 비율은 이미 집계돼 있어서(인상파 40%, 노마드 21%) 추가 비용이 작음
  3. **고른 취향과 결과가 어긋나면 이유 알려주기** (제안): 명화를 골랐는데 그림 전시가 안 나오면 "무료 명화 전시는 미틸라뿐인데, 커플·친구 기준에 못 미쳐 뺐어요 / 유료면 인상파" 식으로 안내 (`서연준호_커플_예상리뷰.md`)

## 2. 밸류체인 병목 5개

팀 취합본에서 '병목'으로 표시된 3개(③ ④ ⑥)에, 서연 Top3를 푸는 데 걸리는 2개(② ⑧)를 더함.

| # | 단계 | 병목 | 근거 (`valuechain/to-check.md`) |
|---|---|---|---|
| 1 | ② 리뷰 정리·태그 | 리뷰_태그 표·등록 담당 미정. Top3 1·2번 해결책이 모두 이 단계에 달려 있음 | 상태 "일부 미정", 두 자료(87건·390건) 기준·번호 다름 |
| 2 | ③ 코스 엔진 | 시간 데이터 없음 → 시간 맞춤 코스 보류 | 인사이트 2, README 보류 |
| 3 | ④ 알리기·유입 | 타깃이 링크를 처음 어디서 보는지(채널)·담당 미정. 그림에서 유일한 점선(가장 비어 있는 단계) | 인사이트 6 |
| 4 | ⑥ ACC 관람 | 관람 완료·관람시간 기록 없음, 전시장 찾기 어려움(B45·B49), 혼잡·매표 줄 | 병목 표시, journey 5·6단계 |
| 5 | ⑧ 관람 후 2문항·공유 | '계획'뿐이라 실제 시간·만족이 ②③으로 돌아오는 고리가 없음 | 상태 "계획", 인사이트 2·3 |

### 1) ② 리뷰 정리·태그
- **아이디어**
  1. **태그를 지금 쓰는 키워드로 고정**: `ACC현재전시_대표키워드.md`의 키워드(체험형, 재미·신기, 어려움·난해, 사진·포토존, 친구와 등)를 리뷰_태그 표의 열로 그대로 씀. 추천 알고리즘이 이미 이 키워드로 돌아서 표 설계를 새로 할 필요가 줄어듦 (제안)
  2. **AI 태그 + 사람 검수 표본만**: 전부 검수하지 않고 전시마다 10개씩만 사람이 확인해 AI 태그 정확도를 잼. 자동 집계가 부풀린 사례가 이미 있음 (김영은 '현대미술·기술' 98%, 단어 검색 '어렵다' 31% vs 집계 6%)
  3. **후기 적은 전시 표시**: 사변적 공동체(8개)·미틸라(30개)처럼 근거가 약한 전시는 카드에 "후기 적음"을 띄우고, 추천 문턱(예: 동행 30%)에 걸려 1~2개 후기로 결과가 뒤집히지 않게 함 (미틸라 29% 사례)

### 2) ③ 코스 엔진 — 시간 데이터
- **아이디어**
  1. **면적 정보 없이도 되는 '시간 범위'로 먼저 출시** (제안): 블로그 관람 시간(79개 글) + 같은 관 기록으로 "약 60분 (빠르게 30 / 천천히 90)"처럼 범위로 보여줌. 정확한 분 대신 "공연 전에 충분/빠듯"만 알려줘도 서연의 걱정("공연에 늦을까 봐")은 줄어듦
  2. **전시 안의 시간 제약부터 넣기**: 김영은 정각 시작(60분 한 바퀴), 인상파 도슨트 시간처럼 이미 아는 고정 시간은 면적과 상관없이 바로 넣을 수 있음
  3. **여유 시간 남기기**: 2시간이면 전시는 90분까지만 채우고 30분은 이동·대기로 둠 (`김서연_예상리뷰.md` "2시간 꽉 채워 여유 없음")

### 3) ④ 알리기·유입
- **아이디어**
  1. **서연이 막히는 곳에 링크 두기** (제안): 서연은 2단계에서 네이버 블로그·인스타를 봄. ACC 관련 블로그·인스타 태그 검색 결과에 노출되도록 "ACC 2시간 코스" 같은 글·카드뉴스를 올림
  2. **공연·야구 일정에 맞춘 알림** (제안): 메인 타깃이 공연·야구로 온 당일치기라, 광주 공연장·경기 일정이 있는 날 그 키워드로 노출 (박대식 밸류체인의 '행사 기간 알림')
  3. **ACC 안 QR** (제안): 이준호 서브 페르소나처럼 ACC 안에서 앱을 발견하는 경우가 있음. 매표소·안내데스크 QR은 ACC 협조가 필요해 ⑨ 대시보드 제안과 묶어서 요청

### 4) ⑥ ACC 관람
- **아이디어**
  1. **입구부터 길 안내**: 결과 카드에 "문화전당역 몇 번 출구 → 어느 입구 → 몇 층"을 고정 칸으로 둠. 노마드(박물관)·김영은 모두 입구 헤맸다는 후기가 있음
  2. **줄 서는 곳 미리 알림**: 인상파 매표·포토존, 노마드 의복 체험, 김영은 우퍼 조끼(선착순)를 카드에 표시
  3. **관람 완료 버튼** (제안): "다 봤어요" 한 번 누르면 실제 관람 시간이 기록됨. 이게 비어 있는 '관람 완료·관람시간' 표가 되고 ③ 시간 데이터 문제도 같이 풀림

### 5) ⑧ 관람 후 2문항·공유
- **아이디어**
  1. **2문항을 1탭으로** (제안): "몇 분 봤어요? (30/60/90)", "취향에 맞았어요? (예/아니요)". 서연처럼 아쉬우면 말없이 떠나는 사람도 답하게 짧게
  2. **인스타 스토리용 결과 카드** (제안): 서연은 인스타 스토리에 올림. 본 전시·사진 한 장·코스를 스토리 크기 이미지로 만들어 주고 링크를 붙이면 공유가 곧 ④ 유입이 됨
  3. **답을 추천 규칙에 되돌리기**: "취향에 안 맞았어요"가 쌓인 전시·동행 조합은 점수를 낮춤. 친구 둘에게 김영은이 맞지 않았던 것처럼(예상 리뷰), 실제 응답으로 확인하고 고침

- 팀 메인 페르소나 김서연은 27세·콘서트(journey-main), 정선아 원본은 32세·브랜드 행사. `박대식/journey/김서연_예상리뷰.md`는 32세 원본 기준
- 아이디어 중 ACC 협조가 필요한 것(ACC 안 QR, 관람 데이터): ACC가 협조할지 근거 없음 (밸류체인 '과금 근거 없음')
