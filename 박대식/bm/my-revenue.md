## 3. 수익화 전에 고려할 것

### 3-1. 신뢰 — 추천이 돈에 흔들리면 안 됨
- 우리 핵심은 "다녀간 사람들의 후기로 고른 추천"(README 결정 문장)
- D(광고)나 E(예매 수수료)가 추천 순위에 들어가면 이 약속이 깨짐 (판단)
- 신희연 조사: 캐치테이블도 광고비를 내면 AI 추천에 더 뜨는지 **확인되지 않음**. 우리도 광고는 추천 점수와 분리하고 "광고" 표시가 필요함

### 3-2. 데이터 권리
- 추천 근거는 네이버 블로그 후기. README 워크플로우는 "원문은 저장하지 않음"
- 블로그 글 요약을 **돈 받는 서비스**에 써도 되는지: **확인 안 함** (네이버 검색 API 상업 이용 조건, 블로그 저작권)
- B(ACC에 데이터 판매)라면 이용자 동의 범위도 정해야 함 (밸류체인 원칙: 동의한 사람만, 목적 끝나면 삭제)

### 3-3. 구매자가 공공기관
- ACC는 국립기관. 구매는 예산 편성·조달 절차를 거침 → 시기·금액 **정보 없음**
- ACC가 살 의사가 있다는 근거 없음 (`valuechain/to-check.md` "과금 근거 없음")
- ACC와 제휴가 없어 공식 데이터(요일·시간대 관람객)를 못 받는 상태

### 3-4. 증명할 숫자가 아직 없음
- 이용자 수, 코스 완료율, 체류 시간, 주변 방문율: **출시 전이라 0**
- 비교 서비스도 매출보다 체류 시간·NPS로 성과를 보여 줌 (LG유플러스 30분 → 71분, ArtLens +30~60분)
- 수익화 전에 무료로 운영해서 숫자부터 모아야 함

### 3-5. 비용
- AI(태그·요약), 서버, 지도 API, 리뷰 등록 인력: **모두 금액 미정** (밸류체인 ①②③)
- 비용을 모르면 손익을 계산할 수 없음

### 3-6. 이용자 특성
- 메인 타깃은 당일치기 타지인 (광주 방문 타지인 10명 중 8명이 당일, README)
- 한 번 쓰고 끝나는 사람이 대부분 → 이용자 구독(A)은 맞지 않음 (판단)
- ACC 무료 전시도 많아서, 무료 전시를 보러 온 사람에게 앱 값을 받기는 어려움 (판단)

### 3-7. 일정
- 팀 프로젝트 마감 2026-12-22. 그 안에 실제 매출은 어려움 → 이번엔 "누가 왜 낼지"까지만 증명 (판단)

## 4. 가장 가능성 높은 후보

### 선정: **C. 공공 지원사업·용역 (먼저) → B. ACC 대시보드 (다음)**

| 기준 | A 이용자 | B ACC 구독 | **C 공공 지원** | D 상권 제휴 | E 예매 수수료 |
|---|---|---|---|---|---|
| 금액 근거 | 비슷한 앱 있음 | 해외 요금표만 | **국내 공모 금액 확인** | 없음 | 없음 |
| 비슷한 사례 수 (9곳 중) | 0 (직접 결제 없음) | 1 (Smartify) | **6 (공공·기관 예산)** | 2 (Qatar 쿠폰, NOL 광고) | 1 (NOL 수수료) |
| 추천 신뢰에 해 없음 | 있음 | 있음 | **있음** | 위험 | 위험 |
| 이용자 숫자 없이 시작 가능 | 아니오 | 아니오 | **예 (예비 단계 공모)** | 아니오 | 아니오 |
| 우리 목적과 맞음 | 보통 | 맞음 | **맞음** (타지인 유입 = 관광 정책 목표) | 보통 | 보통 |

**이유 (판단)**
1. 비교한 9곳 중 6곳이 공공·기관 예산으로 운영됨. 문화 관람 안내는 공공이 돈을 내는 구조가 가장 흔함
2. 금액이 확인된 국내 경로는 관광벤처 공모뿐 (예비 3,000만~7,000만 원, 제17회)
3. 이용자 숫자가 없어도 지원할 수 있는 단계가 있음. 반면 B·D·E는 이용자 숫자가 있어야 팔 수 있음
4. 추천 순위에 돈이 끼지 않아 "후기로 고른 추천"이라는 약속을 지킬 수 있음
5. 지원금으로 무료 운영 → 이용 숫자(완료율·체류 시간) → 그 숫자로 **B(ACC 대시보드)**를 제안하는 순서가 자연스러움. Smartify도 "데이터 리포트가 재계약 이유"였음

**한계**
- 지원금은 매출이 아님. 사업이 계속 가려면 결국 B나 D가 필요함
- 제18회 금액, 광주 지자체 공모, ACC 예산은 **정보 없음**
- 제18회 접수는 2026-05-15에 끝남 → 다음 회차 일정은 **정보 없음**
- 팀 결정 아님. 팀 비교 문서에도 "세 후보 중 기본 모델은 팀 결정 필요"로 남아 있음
