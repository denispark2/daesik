### 고친 점 (2026-11-25, 박대식 "너무 희망적, 20대 남자는 길게 안 씀")
- 긴 존댓말 글 → 앱 리뷰 칸에 남긴 짧은 반말·음슴체 글, 별점 3점
- 친구가 "생각보다 괜찮네"로 돌아서는 결말 삭제 → 나와서도 불만 그대로
- 재방문·권유·재이용 모두 "네" → 애매·모르겠음·쓸 수는 있음
- 헤드폰 시 낭송·자리 옮기기 같은 세부 감상 삭제 (전시에 관심 없는 사람이 적을 내용이 아님)

## 4. 근거와 지어낸 부분
- **블로그 후기에 있는 내용으로 씀**: 스피커로 둘러싼 공간, 대형 스크린 3개, 주제가 어렵다는 평, "볼거리가 적어 지루할 수 있다"는 평(2026-10-24), 매시 정각에 처음부터 시작, 무료 (`ACC현재전시_대표전시물_코스_혼잡도.md` 3번, `ACC현재전시_블로그리뷰취합.md` 2-6, 6번)
- **지어낸 부분 (가상)**: 서비스를 알게 된 경로, 별점, 말투, 두 사람의 반응, 재방문·권유·재이용 답
- **앱 개선 의견**: "정각 시작을 미리 알려줘야 한다"는 후기에 나온 정각 입장 팁을 가상 관람객의 불만으로 바꾼 것

## 5. 근거의 한계 — 20대 남성이 만족할지 (2026-11-25 확인)
- **직접 근거 없음**: 김영은 후기 64개 중 20대 남자, 남자 친구끼리 왔다고 밝힌 글은 0개. 남자가 쓴 게 확실한 글은 1개(2026-11-22, 여자친구와 방문)인데, ACC 전시를 두루 소개하는 글이라 김영은 전시만 평가한 글이 아님
- **동행**: '친구와' 표현 5개, '데이트·커플' 표현 33개 → 친구보다 커플 근거가 강함. 앱이 커플·친구에게 김영은을 추천한 것도 데이트·커플 비율(40%) 영향이 큼
- **불만 근거는 있음**: '어렵다·난해·모르겠다' 20개 글. "볼거리가 적어 지루할 수 있고 난해할 수 있다", "60분이라 다 들어볼 수 없어 아쉽다"는 후기(2026-10-24) → 친구의 투덜거림은 근거가 있음
- **만족 쪽**: 64개 중 57개에 '좋았다·신기·몰입·압도' 같은 말이 있음. 같은 글 안 다른 전시 이야기까지 단어로만 센 값이라 부풀려져 있음. 20대 남성 근거가 없어서, 고친 리뷰는 만족 쪽을 "소리는 신기했다" 정도로만 둠
- **데이터랩 (ACC 전체, 2025-11~2026-10)**: 20대 남성 13.0% (남성 중 가장 많음), 20대 여성 20.1%. ACC 전체 값이라 김영은 전시 관람자 구성은 알 수 없음
- 출처: 로컬 `data/acc_blog/` (깃허브 미업로드), 데이터랩 `성·연령별 방문자.csv`

## 6. 정각 입장과 시간 제약 (2026-11-25 확인)
- **작품 구조**: 아홉 편의 시로 만든 아홉 곡이 **60분 한 바퀴로 반복 재생**되고, **매시 정각에 처음부터 시작**됨 (학예사 안내를 옮긴 2026-09-16 글, 2026-10-17 후기 등)
- **꼭 정각에 들어가야 하는 건 아님**: "정각에 맞춰 처음부터 들을지, 중간에 들어갈지는 관람객의 선택"이라는 글이 있음. 정각 입장은 '처음부터 들으려면 맞추라'는 팁
- **시간 제약 생기는 경우**
  - 60분 관람이면 정각에 들어가야 한 바퀴를 다 들음. 중간에 들어가면 앞부분을 놓치거나 더 머물러야 함
  - 우퍼 조끼 체험 (음악 비트에 맞춰 진동): 입구 접수처에서 선착순으로 이름·번호를 적고, 회차당 4~5명이라는 후기 1개 (2026-11-01). 공식 안내로는 확인 안 함
- **앱에 쓸 점 (제안)**: 김영은 추천 시 "다음 정각까지 ○분" 안내, 우퍼 조끼는 들어가자마자 신청 안내
