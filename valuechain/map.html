병목 · 기회 · 비용 자세히

단계병목 막히면 다음 단계로 못 넘어감기회 비슷한 기업이 잘한 것비용 팀 시간·돈
① 데이터 모으기해결 — 블로그 리뷰 3,200건으로 통합 (박대식 수집)—수집 비용 미정 · 도보 시간 직접 걸어서 측정
② 리뷰 정리·태그리뷰_태그 표의 파일 이름·열 미정스파크: 작품마다 5개 분류 키워드 태그AI 비용 미정 · 태그 검수 시간(신희연)
③ 코스 엔진전시별 관람 시간·도보 시간 없음 → 시간 안 코스 계산 불가Smartify: 관심사 + 꼭 볼 작품 + 시간 → 거리로 경로 계산서버·지도 API 비용 미정 · 개발 담당 미정
④ 알리기·유입타깃이 링크를 처음 보는 채널·담당 미정Smartify: 설치·로그인 없는 웹앱, 무료 요금제로 먼저 들임미정
⑤ 코스 받기입력 개수 2개 vs 4종 미정 → 입력값 열 확정 불가Smartify: 개인 기기로 바로 쓰는 웹앱—
⑥ ACC 관람관람 완료·관람시간 표 미정Smartify: 체류 시간·이탈 지점 수집—
⑦ 다음 갈 곳 (부가)가게 리뷰 표의 출처·열 미정—가게 리뷰 수집 (지도 API 리뷰 수 기준)
⑧ 관람 후 2문항·공유이용 기록 표(세션·단계·시각·값) 열 미정Smartify: 앱 안 설문(NPS)·방문 후 메일로 다음 전시 알림미정
⑨ 운영자 화면ACC 요일·시간대별 관람객 데이터 없음 · 과금 근거 없음Smartify: 관람 데이터 리포트가 기관 재계약 근거정보공개청구(open.go.kr) 시간 · ACC 인터뷰

가장 큰 병목 — 시간 데이터

③ 코스 엔진과 ⑨ 운영자 화면이 모두 전시별 관람 시간·도보 시간에 걸려 있다. 첫 측정 방법은 ⑧ 관람 후 2문항(실제 걸린 시간)과 직접 걸어서 재기. 이 값이 ③으로 돌아가 코스를 고친다.

돈과 데이터 — 지금 상태

돈: 우리에게 들어오는 돈은 0곳, 확보된 돈 줄은 타깃 → ACC·재단 관람료 하나뿐. 데이터: 리뷰·전시·장소 표는 확보, 사용 중에 생기는 기록 5개(입력값·유입 경로·관람 완료·근방 이동·공유)는 미정 → 이용 기록 표 하나로 묶을 수 있음 (to-check 제안).
