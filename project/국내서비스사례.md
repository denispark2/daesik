# 국내 서비스 사례 — 스파크(SPAC) 분석과 우리 프로젝트 벤치마킹

- 프로젝트: OUR ACC JOURNEY (팀 ADS_team4, 타깃: 다른 일정 중 광주에 들른 외지 방문객)
- 작성: 2026-11-20 · 박대식 (Claude 보조)
- 바탕: `전시추천서비스조사.md` 10 · 13 · 14번을 한 파일로 모음. 짝 파일: `project/해외서비스사례.md` (Smartify)
- 표시: 공식 누리집·보도자료와 누리집 화면이 쓰는 공개 데이터(로그인 없이 응답)를 직접 확인함. 확인 못 한 것은 '미확인'. 벤치마킹 내용은 모두 **제안**이다

## 요약
- 스파크는 서울문화재단이 운영하는 공공 예술정보 플랫폼이다. 2026-09-04 개편으로 서울 전역 공연·전시·축제를 다룬다.
- 추천은 두 갈래다. **예술취향지표(SAT)** 16문항 설문 → 16유형, 그리고 **키워드 작품 큐레이션**(조건 카드 → 태그 필터).
- "AI 추천"이라고 소개하지만, 확인한 큐레이션은 **태그 교집합 필터**다. SAT가 추천으로 어떻게 이어지는지는 공개되지 않았다.
- 우리에게 가장 쓸모 있는 것은 **'관람 맥락' 태그 분류**(동반자 유형·관람 시간대·상황)와 데이터에만 있는 **러닝타임·배리어프리** 항목이다.
- 정리: 스파크식 태그 표로 후보 전시를 거르고 → Smartify식으로 남은 시간 안 순서를 짠다.

## 1. 스파크 분석

### 1-1. 개요
- 운영: 서울문화재단 (공공). 문의 spac@sfac.or.kr.
- 연혁: 2025-07-18 '서울예술지원정보포털'(재단 지원 선정작 홍보·아카이브)로 시작했다. 2026-09-04에 '서울예술정보플랫폼'으로 이름을 바꾸고 서울 전역 공연·전시·축제로 넓혔다.
- 콘셉트: '예술작품의 서재'. 책장에서 작품을 꺼내 보는 디자인이다.
- 등록 작품: 큐레이션 대상 작품이 **1,055건**이다 (API 총건수, 2026-11-20 확인).
- 메뉴: 작품정보(월별·신작·자치구25·재단 작품·청년문화패스·서울예술상), Global Selection, 큐레이션, 예술공간(공연장 지도), 리뷰/비평, 소식·이벤트.
- 참고: 예술공간 목록에 「[2026 SPAF] 박본/국립아시아문화전당 〈세 번째 전쟁〉」(아르코예술극장)이 올라 있다. ACC 공동 작품도 서울 공연이면 실린다.

### 1-2. 추천은 두 갈래다

**① 예술취향지표(SAT, SPAC ART TYPOLOGY): 설문 → 16유형**
- 설문 이름 '관람 성향 진단 설문' v1. **16문항, 2지선다**다.
- 4개 축에 4문항씩이고, 축마다 1문항이 **동점 깨기(tiebreaker)** 문항이다.
- 결과는 4글자 조합 **16유형**이다 (MBTI와 같은 구조).

| 축 | 두 극 | 문항 예 (요약) |
|---|---|---|
| 1. 누구와 | **S** 함께 나누기 / **P** 혼자 몰입 | 동행이 못 가게 되면? 사람을 구한다 / 혼자 간다 |
| 2. 무엇에 끌리나 | **A** 감각적 아름다움 / **T** 주제·메시지 | 도록에서 먼저 보는 것? 큰 이미지 / 해설 글 |
| 3. 어떻게 받아들이나 | **C** 분석·구조 / **E** 감정 이입 | 열린 결말이면? 해석을 짠다 / 남은 감정을 믿는다 |
| 4. 어떻게 움직이나 | **O** 계획형 / **F** 즉흥형 | 낯선 도시에서 하루가 비면? 동선·예약을 짠 코스 / 발길 닿는 대로 |

- 유형 예: PTCO '심연의 사색가', STEO '공감의 전달자'(가족·연인과 감동 공유), SAEO '트렌드세터'(화제성 핫플), SACO '스마트 큐레이터'(리뷰 기반 최적 선택, 최적 관람 동선 계획).
- 유형마다 실존 인물을 '대표 인물'로 붙였다 (예: 봉준호, 무라카미 하루키, 크리스토퍼 놀란, 박찬욱, 알프레드 히치콕).
- 보도자료는 "AI 모델 학습에 기반해 … 문항을 설계했다"고 한다. 어떤 모델인지는 공개되지 않았다.

**② 키워드 작품 큐레이션: 조건 선택 → 태그 거르기**
- 큐레이션 화면에서 카드 4장을 고른다. 하나 이상 고르면 'Curate Now'를 누를 수 있다.
- 키워드는 4단계 코드 나무로 되어 있다. 이 나무는 공개 API로 내려온다.

| 카드 | 2단계 (3단계 예) |
|---|---|
| L1 장르·형식 (최대 3개) | 연극·무용·음악·전통·시각예술·다원·융합기술예술·뮤지컬·공예·서커스마술·문학인문·축제행사 12개 |
| L2 감성 스펙트럼 | 힐링·평온, 위로·공감, 감동·벅참, 웃음·유쾌, 설렘·로맨스, 스릴·긴장, 지적자극·사유, 경이·몰입, 향수·추억 등 13개 |
| **L3 관람 맥락** | **동반자 유형**(혼자·연인·친구 2~4인·연령별·단체 10인+), **관람 시간 적합성**(오전·브런치콘서트·마티네·야간·심야·명절), 계절·시즌(신학기·성탄절·송년·수능후 등), **상황·목적**(데이트·날씨·기념일·교육·SNS 인증샷 등) |
| L5 주제·테마 | 사회적 주제 16 · 인문학적 주제 13 · 미학적 테마 15 |
| (L4 접근성 편의) | 배리어프리(휠체어·시각·청각·발달·고령자·영유아), 경제적 접근성(가격대·할인), 관람 조건(**러닝타임**·관람 등급·언어·음성 해설·사진 촬영). **데이터에는 있지만 큐레이션 화면에는 카드가 없다.** |

- 거르는 방식(공개 API로 확인): 고른 코드가 붙은 작품만 남긴다. 그룹을 여럿 고르면 **모든 그룹을 만족하는 작품만** 남는다.
  - 예: 전체 1,055건 → '혼자서 보기 좋은' 157건, '연인(커플)' 78건, 둘 다 56건.
  - 맞는 작품이 없으면 "선택하신 큐레이션 조건에 맞는 작품이 없습니다"라고 보여 준다.
- 큐레이션 설정은 '내 큐레이션'(/curation/mine)으로 저장된다 (회원 기능).

### 1-3. 알고리즘은 공개됐나
- 큐레이션은 **AI라기보다 태그 필터**다. 코드 조건을 맞추는 구조가 API에서 그대로 보인다. 순위를 매기는 규칙은 보이지 않는다.
- **SAT 결과가 큐레이션 키워드로 어떻게 바뀌는지는 확인하지 못했다.** 보도자료는 "SAT 결과를 바탕으로 자동 추천"이라고 하지만, 결과 저장(/mbr/sat/result)은 회원 경로라 열어 보지 않았다.
- **작품에 태그를 누가 붙이는지 미확인.** 예술가 등록, 재단 입력, AI 자동 중 무엇인지 공개 자료가 없다.
- 비판 기사 (51): 어떤 AI를 썼는지, 추천이 얼마나 정확한지, 소규모 작품을 공평하게 노출하는지, 검색어·관람 기록 같은 개인정보를 어떻게 쓰고 언제 지우는지가 공개되지 않았다.

### 1-4. 수익 모델
- 공공 플랫폼이다. 보도자료 기준 "시민 누구나 자유롭게 이용"할 수 있고, 이용자 요금은 없다.
- 예술가 쪽 기능이 함께 있다: **스마트 작품등록**(포스터 한 장 → AI가 작품명·일시·장소 추출), 홍보 이미지 디자인 도구, 스파크 인증 마크.
- 자치구 문화재단 작품도 등록·홍보를 연계한다.

### 1-5. 한계
- 지역이 서울로 한정된다.
- SAT는 16문항이라 짧지 않다. 결과가 추천으로 어떻게 이어지는지 이용자에게 보이지 않는다.
- '리뷰/비평'은 필자 이름이 달린 비평 글이다. 일반 관람객 후기를 모으는 기능은 확인하지 못했다.
- 러닝타임·접근성 키워드는 있지만 큐레이션 화면에서는 고를 수 없다.

### 1-6. 우리 서비스와 비교

| | 스파크 | OUR ACC JOURNEY |
|---|---|---|
| 범위 | 서울 전역 공연·전시 | ACC 한 곳의 전시·공간 |
| 취향 입력 | SAT 16문항 + 키워드 카드 4장 | 동행·남은 시간 선택 (짧게) |
| 결과 | 작품 목록 | 시간 안에 도는 코스 + 나갈 시각 |
| 시간 | '관람 시간 적합성'은 오전·야간 같은 **시간대** | **남은 분 단위 시간** |
| 로그인 | 마이페이지·저장은 회원 | 로그인 없이 |

## 2. 우리 프로젝트에 벤치마킹하는 방법 (제안)

1번을 바탕으로 한 제안이다. 팀 확인이 필요하다.

### 2-1. 가져올 것

| 스파크 | 우리에게 적용 (제안) | 우선 |
|---|---|---|
| **L3 관람 맥락 → 동반자 유형** (혼자·연인·친구·연령별·단체) | 첫 화면 '동행' 선택지를 이 분류에 맞춘다. 공공기관이 이미 쓰는 분류라 설명하기 쉽다. | 높음 |
| **키워드 코드 나무** (대분류 → 세부, 코드 번호) | ACC 전시마다 같은 구조의 태그 표를 만든다 (동행·감성·주제·접근성). 태그를 표로 따로 두면 전시가 바뀌어도 표만 고치면 된다. | 높음 |
| **L4 관람 조건 → 러닝타임** | 전시별 **예상 관람 시간**을 태그 표에 함께 넣는다. 코스 엔진의 필수 값이다. 스파크도 화면에는 안 쓰고 있어, 우리가 쓰면 차별점이 된다. | 높음 |
| **조건이 많으면 교집합 + '없습니다' 안내** | 조건을 다 만족하는 전시가 없으면 조건 하나를 풀어 다시 찾는다. 그래도 없으면 "다 볼 수 없어요"라고 이유와 함께 말한다. | 중간 |
| **L4 배리어프리** (휠체어·영유아·고령자) | '유모차·어르신과 함께' 같은 동행에 엘리베이터·짧은 동선 조건을 붙인다. | 중간 |
| **SAT 4축 중 O/F (계획형·즉흥형)** | 16문항 대신 **한 문항**으로 쓴다. 계획형은 정해진 코스, 즉흥형은 "가까운 것부터 한 곳씩" 안내. | 낮음 (시범 때 검토) |
| **결과에 이름 붙이기** (유형 이름·짧은 설명) | 코스에 이름과 한 줄 이유를 붙인다 (예: "혼자 조용히 70분 코스"). `전시추천서비스조사.md` 10번 정리와 같은 방향. | 중간 |

### 2-2. 따라 하지 않을 것
- **긴 설문(16문항).** KTX 시간이 정해진 당일 방문객에게는 길다. 선택은 2~3개로 끝낸다.
- **실존 인물 '대표 인물'.** 봉준호·하루키 같은 실존 인물을 유형에 붙이는 방식이다. 초상·이름 사용 문제가 생길 수 있고, ACC에 맞지 않는다.
- **로그인이 있어야 저장되는 마이페이지.** 우리는 로그인 없이 쓴다.
- **"AI 추천"이라는 말만 있고 기준이 없는 것.** 우리는 태그 필터·시간 계산이라고 그대로 밝히고, 코스마다 추천 이유를 보여 준다 (비판 기사 (51)가 지적한 부분).

### 2-3. 스파크 vs Smartify, 어디서 무엇을
- **Smartify에서:** 시간 + 관심 → 동선 계산 (코스 엔진, `project/해외서비스사례.md` 2번).
- **스파크에서:** 전시에 붙일 **태그 분류 체계** (동반자·시간대·접근성·러닝타임), 그리고 조건 교집합 방식.
- 둘을 합치면: 스파크식 태그 표로 후보 전시를 거르고 → Smartify식으로 남은 시간 안에서 순서를 짠다.

### 2-4. 아직 확인할 것
- ACC 전시별 예상 관람 시간 (데이터랩의 ACC 평균 체류 56분은 시설 전체 값이다. 전시별 값이 아니다.)
- 전시 사이 도보 시간
- ACC 전시에 태그를 누가 붙일지 (우리가 직접 / AI 초안 + 검수)

## 3. 수익 구조와 성과

스파크 자체의 매출·이익은 없고, 사업비도 따로 공개된 적이 없다. 이용자에게 무료이고, 서울시 출연기관인 서울문화재단이 예산으로 운영하는 구조다. 그래서 **돈이 아니라 "재단이 지원한 작품을 시민에게 연결하는 성과"**로 보는 것이 맞다.

### 3-1. 수익 구조

| 구분 | 내용 |
|---|---|
| 서비스 수익 | 없음. 시민 누구나 무료로 이용 (보도자료) |
| 서비스 비용·매출 | 공개 안 됨. 스파크 구축·운영비, 방문자 수는 찾지 못함 (**미확인**) |
| 운영사 예산 (참고) | 서울문화재단 2026년 총 사업비 **1,481억 원** (전년 대비 +106억 원). 지원사업 317억, 바우처 739억, 공간운영 280억. 수탁사업 포함 실질 운영 예산 약 1,700억 원 (기자간담회 기사). 재단 누리집 예산총괄표(본예산, 재단 자체 회계) 세출은 610억 7,935만 원 (2025년 618억 5,943만 원 대비 -1.3%). 두 숫자는 기준이 달라 함께 비교하면 안 됨 |
| 스파크가 기대는 돈 | 서울시·재단이 매년 **약 170억 원으로 약 500편**의 예술 작품을 지원한다. 스파크는 이 공공 지원작을 시민이 찾아보게 만드는 창구로 시작했다 (재단 정보관리팀 글) |

**이 플랫폼의 목적은 직접 매출이 아니라 공공 지원의 효과를 키우는 것이다.**
- 지원금으로 만든 작품이 "언제 어디서 하는지 모르는" 문제를 푸는 것이 출발점이다.
- 예술인에게는 홍보비 부담을 줄이는 공공 홍보 채널, 나아가 **티켓 판매까지 이어지는 유통 경로**를 내세운다 (오픈 당시 소개).
- 즉, 재단 예산으로 무료 정보·큐레이션을 제공하고, 실제 매출(티켓)은 각 공연·전시 쪽에서 생기는 구조다.

### 3-3. 재단이 내세우는 성과·계획 (돈 대신 연결 지표)
- **예술인 쪽:** 지원 선정 직후부터 스파크로 홍보를 시작한다. 현장 간담회에서 가장 많이 나온 요구가 '홍보 지원'이었다는 것이 재단 설명이다.
- **유통 쪽:** 2026년 3월부터 부산·강원·전북·충남·충북 광역문화재단과 협약해 지역 간 작품 유통을 넓힌다는 계획이다 (협약 체결 여부·실적은 **미확인**).
- **시민 쪽:** SAT·큐레이션·마이페이지로 "내 취향 작품"을 찾게 한다. 다만 이용자 수, 추천을 보고 예매로 이어진 비율 같은 성과 지표는 공개되지 않았다 (**미확인**).

### 3-4. 우리 프로젝트에 주는 시사점 (제안)
- 공공 서비스는 **매출 대신 무엇으로 성과를 보여 줄지**를 처음부터 정해야 한다. 스파크는 지표를 공개하지 않아 효과를 확인하기 어렵다는 비판을 받는다 (1-3, 비판 기사 (51)).
- 우리는 처음부터 쌓을 지표를 정해 두자: ① 코스 이용 수 ② 코스대로 다 본 비율 ③ 실제 관람 시간(관람 후 2문항) ④ '다음 갈 곳' 선택 비율 ⑤ 기차 시간 안에 나간 비율.
- ACC 쪽 성과로 말하면: ACC 평균 체류 56분(데이터랩)을 기준값으로 두고, 코스 이용자 체류시간·관람 전시 수가 늘었는지를 본다.
