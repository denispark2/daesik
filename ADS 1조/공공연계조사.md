# 수요예측 서비스를 공공 소상공인 지원사업과 연계할 수 있나 (박대식)

작성 2026-11-17 · 대상: 앱기획안.md의 베이커리 사장님 앱(수요 예측·생산량·진단)

## 1. 결론 **[Claude 판단]**
- **가능함. 이미 같은 형태의 사업이 있음.**
  1. 소상공인시장진흥공단 **스마트상점 기술보급사업 S/W형** — 모집 분야에 "매출분석 S/W, 재고관리 S/W"가 있고, 구독형(SaaS) 구독료를 국비로 지원
  2. **광주 서구**가 이미 "AI 기반 매출·수요 예측 솔루션"을 소상공인에게 **무상 제공**하는 실증사업을 함 (2026)
- **단, 지금 바로는 안 됨.** 스마트상점은 "상용화된 기술"만 받고, 재무제표·신용등급·보증보험이 필요 → **회사를 세우고 실제 서비스를 출시한 뒤** 신청 가능
- 현실적 순서: ① 시범 가게로 효과 증명 → ② 지자체 실증사업(광주 서구 방식) → ③ 상용화 후 스마트상점 S/W형 공급기업 신청

## 2. 경로별 정리

### 2-1. 스마트상점 기술보급사업 S/W형 (소상공인시장진흥공단) — 공고문 원문 확인
| 항목 | 내용 (2026년 공고 기준) |
|---|---|
| 대상 기술 | "공고일 기준 상용화되어 서비스가 가능한 월 구독 형태 소프트웨어 (매출분석, 재고관리, 예약관리, 고객관리 등)" |
| 지원 | 소상공인 구독료를 **상점당 연 30만 원(월 2.5만 원, VAT 별도)** 까지 국비 지원, 보조율 **90~100%**, 1년 + 활용 확인 후 1년 연장(최대 2년) |
| 제외 | 판매형 소프트웨어, **프랜차이즈별 전용 시스템**, S/W 개발 지원 → 개인 빵집용인 우리 앱은 해당 안 됨(유리) |
| 데이터 제공 의무 (2026 신규) | 대시보드·카톡 알림·일주월 리포트, **비교 기준을 함께 보여주는 지표**, 자연어 경영분석 = 적합 / 엑셀 원시자료, 해석 없는 숫자 = 부적합 → 우리 W7 진단 리포트 방식과 맞음 |
| 가격 | 공단 표준가격의 120% 이내 |
| 공급기업 조건 | 상용화(개발 단계 불가), 최근 2년 표준재무제표, 신용평가등급 확인서, **지급보증보험 증권 발급 가능**, 무상유지보수(지원기간 이상), 컨소시엄 불가 |
| 평가 | 서류 → 서면(가격 40·재무 40·신용 20, 60점 이상) → 대면(기술경쟁력·사업관리·대표자·사후관리 각 15·15·10·15, 정책부합 10 등, 70점 이상) |
| 일정 | 2026년 공급기업 접수 1/12~1/23 (**연 1회**, 수요 따라 추가 모집 가능) |
| 주의 | "풀(pool)에 등록돼도 소상공인 수요가 없을 수 있음" — 사장님이 직접 고름 |
출처: 소상공인시장진흥공단 「2026년 스마트상점 기술공급기업 모집 공고」(2025-12-30) — https://grant-documents.thevc.kr/286160_2026%EB%85%84%2B%EC%8A%A4%EB%A7%88%ED%8A%B8%EC%83%81%EC%A0%90%2B%EA%B8%B0%EC%88%A0%EB%B3%B4%EA%B8%89%EC%82%AC%EC%97%85%2B%EA%B8%B0%EC%88%A0%EA%B3%B5%EA%B8%89%EA%B8%B0%EC%97%85%2B%EB%AA%A8%EC%A7%91%2B%EA%B3%B5%EA%B3%A0(%EC%B5%9C%EC%A2%85).pdf

**[Claude 판단] 가격 시사점**: 국비 한도가 월 2.5만 원 → 구독료를 **월 2.5만 원 이하**로 맞추면 사장님 부담이 거의 0 (수요검토.md 7번의 "유료 구독 참여 낮음" 문제를 푸는 길)

### 2-2. 지자체 실증사업 — 광주 서구 사례
| 항목 | 내용 |
|---|---|
| 내용 | 광주 서구가 외식 솔루션 기업 **먼슬리키친**과 '소상공인 디지털 전환 실증사업' 협약 → **AI 기반 매출·수요 예측 솔루션을 소상공인에게 무상 제공**, 6개월 테스트베드. 고객 소비 데이터로 재방문 가능성 높은 손님에게 맞춤 프로모션 자동 실행 기능 포함 |
| 확대 | 성과 분석 후 구 전체로 확대 방침. 세정아울렛 중심 5년 최대 100억 원 상권 활성화 사업과 연계 |
| 미확인 | 대상 가게 수·업종, 예산 출처, 협약 정확한 날짜 |
출처: 쿠키뉴스 (2026-03-04) — https://www.kukinews.com/article/view/kuk202603040108

**[Claude 판단]**: 상용화 전이라도 들어갈 수 있는 가장 현실적인 길. 단, 같은 광주에 **이미 경쟁 업체(먼슬리키친)가 들어가 있음** → 차별점(빵집 제품별 생산량·재료·폐기)을 분명히 해야 함
