# 실제 가게 POS 매출 기록 받는 방법 (박대식)

작성 2026-11-17 · 목적: 가게를 섭외하면 가상데이터(앱시안/가상데이터/) 대신 실제 기록으로 앱 예측을 확인

## 1. 결론
- **받을 수 있음.** 많이 쓰는 POS는 매출을 엑셀로 내보내는 기능이 있음 (토스플레이스는 공식 안내로 확인, 나머지는 **미확인**)
- **단, POS에는 "판매"만 있음.** 앱에 꼭 필요한 **생산 수·폐기 수·품절 시각은 POS에 없음** → 사장님이 따로 적어줘야 함

## 2. POS별 내보내기

| POS | 방법 | 상품별 판매 | 확인 | 출처 |
|---|---|---|---|---|
| **토스플레이스** | 포스 메뉴 → 매출 리포트 → 매출현황 → 엑셀 내보내기 → 기간 선택 → 파일 만들기 → 비밀번호 설정 → 받기 | '상품 주문' 시트: 주문기준일자, 주문시작시각, 주문채널, 상품명, 카테고리, 수량, 상품가격, 할인, 실판매금액 | 공식 안내 | https://tossplace.com/story/salesreport |
| OKPOS | POS 매출현황에 영수증별·분류별·**상품별**·월별 매출 메뉴 | 화면 조회는 됨 | 엑셀 저장 경로 **미확인** | SK쉴더스 OKPOS 매뉴얼 — https://www.skshieldus.com/assets/file/SMARTPOS_OKPOS_MANUAL.pdf |
| 페이히어 | 통합 대시보드에서 상품·주문 내역 확인 | 상품별 분석 있음 | 엑셀 내보내기·API **미확인** | 벤처스퀘어 — https://www.venturesquare.net/1089597/ |
| 기타 (배민포스 등) | – | – | **미확인** → 섭외한 가게 POS 이름 듣고 확인 | – |

- 공식 API로 자동으로 받는 방법은 이번에 확인 못 함. 시범 단계에서는 **엑셀 내보내기**가 현실적 **[Claude 판단]**

## 3. 우리 데이터 형식에 맞추기
앱시안/가상데이터/판매기록.csv 열 기준

| 우리 열 | 어디서 | 비고 |
|---|---|---|
| 날짜 | POS (주문기준일자) | |
| 요일 | 날짜로 계산 | |
| 날씨 | 기상청 과거 날씨 | 가게 동네 기준 |
| 제품 | POS (상품명) | 옵션·세트 정리 필요 |
| 판매수(POS) | POS (수량을 날짜·상품별로 합침) | 취소 건 제외 |
| 판매가 | POS (상품가격) | 할인 전·후 둘 다 보관 |
| **생산수** | **사장님 기록** | POS에 없음 |
| **폐기수** | **사장님 기록** (또는 생산수 − 판매수) | 할인 판매·직원 식사·나눔은 따로 표시 |
| **품절여부·품절시각** | **사장님 기록** | 없으면 "마지막 판매 시각"으로 추정 가능 (POS 주문시작시각) — 정확하지 않음 |

**[Claude 제안] 사장님 기록 부담 줄이기**
- 종이 한 장: 날짜 / 제품 / 만든 수 / 남은 수 → 하루 1분
- 최소 기간: 같은 요일 비교를 하려면 **4주 이상**, 날씨 효과까지 보려면 8~12주

## 4. 받을 때 지킬 것
1. **동의서 먼저** (사장님 서명): 쓰는 목적(수업 프로젝트 예측 실험), 받는 범위(상품별 판매만), 보관 기간·파기, 가게 이름 공개 여부, 외부 제공 안 함
2. **'상품 주문' 시트만 받음.** '결제' 시트(결제 수단·매입사·취소 시각)는 받지 않음 — 필요 없고, 손님 결제 정보가 섞일 수 있음
3. **회원·전화번호·카드번호 열이 있으면 지우고 받음** (사장님 앞에서 같이 확인)
4. **원본은 공개 저장소에 올리지 않음.** daesik·팀 저장소 모두 공개 → 실제 매출은 로컬에만 두고, 올릴 때는 가게 이름을 지우고 집계·비율만 올림 **[Claude 제안 — 업로드 규칙 확인 필요]**
5. 엑셀 비밀번호는 파일과 따로 전달받고 어디에도 적지 않음

## 5. 섭외 때 물어볼 것
1. 어떤 POS 쓰세요? (이름)
2. 매출을 엑셀로 내려받아 본 적 있으세요?
3. 지난 몇 달 기록이 POS에 남아 있나요?
4. 하루에 만든 수·남은 수를 적어둔 게 있나요? (노트·엑셀)
5. 앞으로 4주 동안 하루 1분 기록이 가능할까요?
6. 가게 이름을 발표 자료에 써도 될까요?
