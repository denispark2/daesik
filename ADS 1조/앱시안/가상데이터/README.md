## 가상 빵집 설정 **[Claude 가정]**
- 단일 매장 동네 베이커리, 사장님 1명 + 파트타임 1명
- 영업: 화~일 09:00~20:00, 월요일 휴무
- 기간: 2026-08-25 ~ 2026-11-15 (12주, 영업일 72일)
- 2026-10-23~25: 사장님이 근처 빵 축제 부스에 나가 매장 손님이 25% 줄었다고 가정 (행사 모드 시안용)
- 날씨: 맑음·흐림·비를 무작위로 넣고, 비 오는 날 손님 20% 감소, 흐린 날 5% 감소로 가정
- 지금 생산 방식: 사장님이 "같은 요일 최근 3주 판매량 평균 × 1.12"로 감으로 만든다고 가정 → 앱 도입 전 상태
