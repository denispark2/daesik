# 화면 목록 (초안) — 베이커리 사장님 앱 (박대식)

작성 2026-11-17 · 기준: 앱기획안.md (휴대폰 앱 + 웹, POS 연동, 가상 데이터) · 화면 구성은 **[Claude 제안]**

## 화면 흐름
```
[처음 설정 · 웹]  가게 정보 → POS 연결 → 재료 단가 → 레시피 → 유지비
        ↓
[매일 · 휴대폰]  오늘 생산 계획 → 재료 준비/구매 목록 → (영업) → 마감 입력(생산·폐기·품절)
        ↓                                         ↑ 판매 수는 POS에서 자동
[매주 · 웹]  경영 진단 리포트 → 생산량·가격 조정 제안 → 사장님이 적용/보류
```

## 휴대폰 앱 (매장에서 매일)
| # | 화면 | 보여주는 것 | 사장님이 하는 것 | 가상 데이터 예시 |
|---|---|---|---|---|
| M1 | **홈 (오늘)** | 오늘 날씨·요일, 예상 매출, 예상 이익, 알림(행사·비 예보) | 한눈에 확인 | 화요일·흐림, 예상 매출 37만 원 |
| M2 | **오늘 생산 계획** | 제품별 추천 생산 수 + 이유(요일·날씨·최근 판매), 지난주 같은 요일 판매 | 수량 수정 후 "확정" | 소금빵 32개 (지난 화요일 판매 30개, 흐림 −5%) |
| M3 | **재료 준비·구매 목록** | 확정한 생산량 × 레시피 → 재료별 필요량, 재고 대비 부족분, 구매 단위로 올림 | 체크 / 발주 메모 | 발효버터 약 1.6kg 필요 |
| M4 | **실시간 판매 (POS)** | 제품별 오늘 판매 수 vs 생산 수, 남은 수 | 품절 시 "품절" 누르기(시각 기록) | 소금빵 28/32 판매 |
| M5 | **마감 입력** | POS 판매 수 자동 표시 | 폐기 수 입력, 메모 | 크루아상 폐기 6개 |
| M6 | **오늘 결과** | 실제 매출·이익, 예측과 차이, 폐기 손실액, 놓친 매출(품절 추정) | 확인 | 폐기 손실 5,982원 |
| M7 | **알림** | 내일 비 예보, 주변 행사, 재료 부족, 진단 리포트 도착 | 탭해서 이동 | "토요일 근처 행사 — 생산 +20% 검토" |

## 웹 (사무실·집에서 가끔)
| # | 화면 | 보여주는 것 | 사장님이 하는 것 |
|---|---|---|---|
| W1 | **처음 설정 / 가게 정보** | 영업 요일·시간, 휴무일 | 입력 |
| W2 | **POS 연결** | 연결 가능한 POS 목록, 연결 상태, 마지막 동기화 시각 | 연결 (실제 연동 가능 POS는 **미확인** → 시안에서는 화면만) |
| W3 | **재료 단가 관리** | 재료·구매 단위·가격, 가격 변동 기록 | 추가·수정 (거래명세서 사진 등록은 다음 버전) |
| W4 | **레시피 관리** | 제품별 재료·사용량 → 1개 원가·원가율 자동 계산 | 추가·수정 |
| W5 | **유지비 관리** | 월 고정비 항목, 하루·제품당 배분액 | 입력 |
| W6 | **판매 기록** | 날짜·제품별 생산·판매·폐기·품절 표, 엑셀 내려받기 | 조회·수정 |
| W7 | **주간 경영 진단 리포트** | 매출·이익, 원가율, 제품별 공헌이익 순위, 폐기율, 품절률, 손익분기 판매량, 예측 정확도 | 확인 |
| W8 | **조정 제안** | 생산량 조정(자주 남는/모자라는 제품), 원가율 기준을 넘은 제품 알림 + 가격 바꿔보기(앱은 가격 추천 안 함), 적용 시 예상 효과 | 생산량 적용 / 보류, 판매가 직접 입력 |
| W9 | **행사 모드 설정** | 행사 날짜·장소, 부스 운영 여부, 지난 행사 판매 기록 | 행사 등록 → 생산 계획에 반영 |

## 시안에 넣을 대표 숫자 (가상데이터/README.md 기준)
- 12주 매출 2,730만 원, 영업이익 909만 원 (사장님 인건비 제외)
- 폐기율 13~15% + 품절된 날 33~50% → W7 리포트 첫 줄 메시지: "남는 날과 모자라는 날이 같이 많아요"
- 원가율 높은 제품: 우유식빵 32.3%, 마들렌 31.3% → W8 원가율 알림·가격 바꿔보기 예시 (사장님이 가격 입력)
- 공헌이익 1위 소금빵 (12주 663만 원) → W7 순위 예시
