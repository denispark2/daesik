## 3. 컨셉 결정 과정
1. 형식: 마감이 당일이라 영상 대신 **이미지 6컷**으로 결정
2. 시간 컨셉(1996 → 2026 → 2056, 3대 가족) → 탈락
3. 「갓 지은 도시」(미니 일꾼이 햇반과 쌀알로 도시를 지음) → 방향은 채택
4. 스케일 뇌절 버전(부엌 → 서울 → 지구 → 우주) → 탈락
5. 분양 광고 패러디(공사 현장 개그) → 공사 쪽으로 치우쳐서 탈락
6. 미니 도시 시민의 하루(쌀알 중심 개그) → 쌀이 아니라 햇반 제품에 포인트를 둬야 해서 수정
7. **「햇반 월드의 하루」**: 온 세상이 햇반 제품 모양인 세상의 하루 → 최종 채택
   - 전자레인지 찜질방, 햇반 모양 달, 햇반을 쌓은 아파트는 빼기로 함
   - 햇반을 먹는 장면을 최소 한 컷 넣기로 함 (점심, 저녁)
   - 저녁 컷 후보 중 헬스장(B안)을 선택함

## 4. 최종 컨셉: 「햇반 월드의 하루」
- 주제: 햇반이 지을 미래
- 한 줄 요약: 집도, 버스도, 회사도 전부 햇반인 세상의 평범한 하루
- 햇반 특징 활용: 흰 용기, 필름 뚜껑, 모서리 탭, 3개입·12개입 묶음
- 이미지 생성 도구: ChatGPT

### 공통 스타일
```
초현실적인 광고 사진, 실제 크기 사람과 도시, 세상의 모든 건물·차·물건이 흰색 둥근 사각형 즉석밥 용기 모양, 투명 필름 뚜껑과 한쪽 모서리의 뜯는 탭까지 그대로 재현, 밝고 깨끗한 색감, 코믹한 상황, 4:5 세로 비율, 글자와 로고 넣지 말 것
```

### 6컷 프롬프트
**컷1: 아침**
```
거대한 흰 즉석밥 용기 모양의 집, 침실 창문이 투명 필름 뚜껑으로 덮여 있다. 잠옷 입은 한국인 남자가 커튼 대신 필름 뚜껑의 모서리 탭을 잡고 쫙 뜯어 젖히자 아침 햇살과 하얀 김이 쏟아져 들어온다. 개운한 표정
```

**컷2: 출근**
```
도시 도로 위, 흰 즉석밥 용기 3개가 묶음 포장처럼 붙어 있는 3량 연결 버스가 달린다. 옆 고가 위로는 용기 12개가 2줄로 붙은 지하철이 지나간다. 버스 필름 창문 안에 직장인들이 빽빽하게 서 있다
```

**컷3: 회사**
```
넓은 사무실, 책상 칸막이가 전부 흰 즉석밥 용기다. 수십 명의 직장인이 각자 용기 한 칸 안에 앉아 노트북을 하고, 위에서 내려다본 구도라 묶음 박스처럼 보인다. 한 명은 필름 뚜껑을 덮고 졸고 있다
```

**컷4: 점심**
```
점심 12시 정각, 즉석밥 용기 모양 건물들 사이 광장과 옥상, 용기 모양 공원 벤치에서 수백 명의 직장인이 일제히 흰 즉석밥의 필름 뚜껑을 동시에 뜯는다. 도시 곳곳에서 하얀 김이 한꺼번에 피어올라 하늘에 거대한 김 구름이 생긴다. 높은 곳에서 내려다본 구도, 다들 숟가락을 들고 신난 표정
```

**컷5: 헬스장**
```
헬스장, 근육질 한국인 남자가 즉석밥 3개입 묶음을 덤벨처럼 들고 이를 악물고 있다. 옆 랙에는 3개입, 6개입, 12개입 묶음이 무게별로 정리되어 있다. 트레이너가 옆에서 진지하게 응원한다
```

**컷6: 저녁**
```
밤, 즉석밥 용기 모양의 아늑한 집 안. 식탁, 의자, 조명까지 전부 흰 즉석밥 용기 모양이다. 3대 한국인 가족(할머니, 엄마, 아빠, 아이)이 둘러앉아 김이 모락모락 나는 즉석밥과 반찬을 함께 먹으며 크게 웃는다. 아이 볼에 밥풀이 붙어 있다. 따뜻한 주황 조명, 행복한 분위기
```

### ChatGPT 사용 팁
- 첫 메시지로 공통 스타일을 고정하고, 같은 채팅창에서 6장을 모두 만든다
- 일부만 고칠 때는 선택(편집) 도구로 그 부분을 칠하고 요청한다
- 무료는 하루 생성 장수가 적다 → 막히면 Gemini로 넘어간다
- 생성 화면은 매번 캡처한다 (제출할 때 증빙으로 냄)
