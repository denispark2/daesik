# 박대식 페르소나 — ACC를 안내하는 가상 캐릭터 3개

작성 2026-11-19 · 박대식 (Claude 보조)
바탕: `박대식/brand/my-ideas.md` (5~7세 아이 캐릭터 + 부모용 존댓말 안내, 타지에서 방문한 가족, 특정 전시에 맞추지 않음)
근거 번호: N = 네이버 방문자 리뷰, B = 네이버 블로그 리뷰 (`정선아/reviews/`)
캐릭터 이름·나이·설정은 모두 **(상상)**.

| 캐릭터 | 누구에게 | 언제 |
|---|---|---|
| 물감이 (6살 꼬마 화가) | 아이 | 기본 — 미술 전시 |
| 도전이 (7살 체험 탐험대원) | 아이 | 체험형 전시 |
| 모아 (가족 길잡이) | 부모 | 요금·예매·주차·편의 안내 |

## 1. 물감이 — 6살 꼬마 화가 (기본 캐릭터)
**1줄 소개**: 그림 속에 숨은 색과 이야기를 찾아내는 6살 꼬마 화가

**성격**: 눈 밝은 · 수다스러운 · 감탄 잘하는

**말투 규칙**
1. 짧은 반말 문장으로 말한다.
2. 답을 알려주지 않고 질문으로 끝내서 아이가 직접 찾게 한다. ("~찾아볼래?", "~같아?")
3. 작품·화가 이름 대신 색·모양·느낌으로 말한다. (전시가 바뀌어도 쓸 수 있게)

**문장 예시**
- "이 그림 속에 어떤 색이 숨어 있을까? 같이 찾아볼래?"
- "광주는 처음이지? 이 그림은 어떤 소리가 날 것 같아?"

**핵심 메시지**
1. 그림을 잘 몰라도 재밌게 볼 수 있어. (근거: B36 — 미술을 잘 몰라도 아이와 원화를 봄)
2. 엄마 아빠랑 이야기하면서 보면 더 재밌어. (근거: B11 — 전시를 보며 아이와 나눌 질문을 떠올림)
3. 다 보고 나면 내 손으로 하나 남겨 가자. (근거: N20 — 아이들이 좋아한 스탬프 체험)

**쓰지 않는 말**
1. 어려운 미술 용어 (예: "OO주의", "OO기법")
2. 특정 작품·화가 이름 (전시가 매번 바뀜)
3. "만지지 마", "조용히 해" 같은 꾸중 — 관람 규칙은 모아가 부모에게 안내

## 2. 도전이 — 7살 체험 탐험대원 (체험형 전시용)
**1줄 소개**: 실패해도 "한 번 더!"를 외치는 7살 체험 탐험대원

**성격**: 호기심 많은 · 씩씩한 · 포기 안 하는

**말투 규칙**
1. 감탄사로 시작하는 신나는 반말로 말한다. ("우와!", "좋아!")
2. 몸을 쓰는 말(뛰다·굴리다·찾다·잡다)을 많이 쓴다.
3. 실패하면 "다시 해보자"로 이어준다.

**문장 예시**
- "한 번 더 해볼래! 이번엔 살살 해볼까?"
- "우와, 광주에서 탐험 시작이다! 준비됐어?"

**핵심 메시지**
1. 몸으로 해보면 더 재밌어. (근거: B43 — 몸을 쓰는 어린이체험관)
2. 실패해도 괜찮아, 다시 하면 돼. (근거: N31 — 실패한 뒤 "이번에는 조금 약하게 해볼까?" 하며 다시 도전)
3. 끝까지 해보면 뿌듯해. (근거: N31 — 집중력과 도전하는 태도를 배운 시간)

**쓰지 않는 말**
1. "1등", "누가 더 잘해?" 같은 경쟁하는 말
2. "위험해", "다쳐" 같은 겁주는 말
3. 특정 체험 이름 (체험 프로그램이 바뀜)

## 3. 모아 — 가족 길잡이 (부모 안내 담당)
**1줄 소개**: 광주에 처음 온 가족에게 꼭 필요한 것만 차분히 알려주는 ACC 길잡이

**성격**: 차분한 · 꼼꼼한 · 배려 깊은

**말투 규칙**
1. 부모에게 존댓말로 말한다.
2. 한 문장에 정보 하나만 담는다.
3. 바뀌는 정보(요금·회차·휴관)는 단정하지 않고 "전시마다 달라요", "확인해 주세요"로 말한다.

**문장 예시**
- "체험은 회차 예매가 필요한 경우가 많아요. 미리 예약해 주세요."
- "유료 전시를 보시면 주차 3시간 할인을 받을 수 있어요."

**핵심 메시지**
1. 미리 알면 편해요 — 예매·대상 나이·주차. (근거: B43 회차 예매·대상 나이, B34 예약 마감, N20·B1·B24 주차 3시간 할인)
2. 부모님도 쉬어 가실 수 있어요. (근거: N21 — 아이가 노는 동안 앉을 의자가 많음)
3. ACC에서 광주 여행이 이어져요 — 짐 보관, 우산 대여, 충장로·동명동. (근거: B49 무료 짐 보관, N27 우산 대여, B13·B39·B49 주변 코스)

**쓰지 않는 말**
1. 확인 안 된 숫자·날짜를 단정하는 말 (예: "항상 무료예요", "언제든 들어갈 수 있어요")
2. 반말·아이 말투 (아이 말투는 물감이·도전이 몫)
3. "꼭 가야 할 최고의 곳" 같은 과장된 홍보 문구
