## 프롬프트

```
너는 모바일 앱 UI 디자이너야.
첨부한 기획서(brand/one-page-plan.md)의 'OUR ACC JOURNEY' 앱 시안을 만들어 줘.
문구는 첨부한 brand/brand-skill.md 규칙을 먼저 읽고 따라 줘.

[결과물]
- HTML 파일 1개. 세로 390×844 휴대폰 화면 6장을 가로로 나란히 놓는다.
- 각 화면 위에 화면 번호와 이름을 작게 적는다.
- 버튼을 누르면 다음 화면으로 넘어가게 만든다 (화면 1 '코스 받기' → 화면 2, '길 안내 보기' → 화면 3, '코스로 돌아가기' → 화면 2).
- 외부 이미지·폰트·라이브러리는 쓰지 않는다. 아이콘은 선으로 그린 단순한 SVG.

[누구를 위한 앱]
- 타깃: 다른 일정(여행·공연·경기·비엔날레) 중 광주에 들른 외지 방문객
- 말하는 사람: 돌아가는 기차 시간부터 묻는 ACC 역무원 (상상 캐릭터)
- 핵심: 남은 시간 안에 볼 전시 1~2개와 다음 갈 곳을 시간 순서로 짜 준다

[공통 디자인 규칙]
- 콘셉트: 기차역 승강장 안내판과 기차표. 차분하고 실속 있는 느낌
- 시간 숫자가 화면에서 가장 크게 보인다
- 색은 3가지만:
  - 남색 #1F2A44 — 위쪽 바, 제목, 본문 글씨
  - 크림 #F5F1E8 — 화면 배경, 카드 배경
  - 주황 #E8792B — 시간 숫자, 주요 버튼, 지금 단계, 경고 띠
  - 비활성·보조 글씨·'데이터 필요' 카드는 남색 투명도 50%. 다른 색은 넣지 않는다
- 글씨 크기: 시간 숫자 굵게 40pt 이상 / 제목 20pt / 본문 16pt / 버튼 18pt
- 버튼은 화면 아래쪽, 높이 56 이상
- 확인 안 된 정보 옆에는 작은 테두리 표시 '확인 필요'

[문구 규칙]
- 해요체만 쓴다. "~습니다", 반말은 쓰지 않는다
- 한 문장 40자 이하, 한 문장에 정보 하나
- 느낌표·이모지·감탄사 없음
- 쓰지 않는 말: "다 보세요", "하루 종일", "항상", "무조건", "언제든", "담론" 같은 전문 용어
- 5·18 공간(민주평화교류원·옛 도청) 칸에서는 "빨리", "얼른", "서둘러요"를 쓰지 않는다. 시간이 모자라면 "다음에 천천히 와요"
- 넣지 않는 것: 관람료, 실제 전시 이름, 가게 이름, 사진, 지도 이미지 → "전시 A", "동네 B"로 쓴다
- 숫자는 아래 [확인된 정보]와 예시 기차 시간만 쓴다. 나머지 시간·거리는 지어내지 말고 '확인 필요'로 둔다

[확인된 정보 — 이 숫자만 쓴다]
- ACC 실내 시설 10:00~18:00 / 문화창조원·문화정보원은 수·토 20:00까지 / 휴관 매주 월요일·1월 1일
- 광주송정역 → 문화전당역 지하철 1호선 24분 (열차 탑승 시간만)
- 짐 보관: 아시아문화광장 방문자센터, 18:00에 닫음
- 예시 기차 시간 "5:00", 지금 시각 "2:00", 나갈 시각 "3시 반"은 화면 예시용 (상상)

[화면 1 — 첫 화면 (입력)]
- 맨 위: "OUR ACC JOURNEY" + 역무원 모자 아이콘
- 말풍선: "돌아가는 기차가 몇 시예요?"
- 남은 시간 입력 (둘 중 하나 고름)
  - 기차 시간: 시·분 휠, 숫자는 주황으로 크게
  - 기차가 아니면: 머물 시간 버튼 3개 — 1시간 · 2시간 · 반나절
- 지금 시각 작게: "지금 2:00"
- 동행 버튼 4개: 혼자 · 친구·연인 · 아이와 · 부모님과
- 지금 있는 곳: 기본값 "문화전당역" 작게 (눌러서 광주송정역·ACC 도착으로 바꿈)
- 맨 아래 '코스 받기' 버튼: 시간 고르기 전 흐리게, 고르면 주황

[화면 2 — 코스 결과]
- 위 고정 바: "기차 5:00 · 남은 시간 1시간 30분"
- 기차 노선도처럼 점과 선으로 잇는 세로 타임라인:
  송정역 → 지하철 24분 → 문화전당역 → 전시 A → 나갈 시각 → 동네 B → 송정역
  - 칸마다 시각과 머무는 시간을 크게. 걷는 시간은 '확인 필요'
  - 나갈 시각 칸은 주황 강조: "3시 반에는 나가요."
  - 지금 할 칸은 주황 점, 지난 칸은 흐린 점
- 전시 A 칸 아래 기대치 카드: "좋았다는 후기: …" / "아쉽다는 후기: …" 한 줄씩
- 혼잡 예측 자리: "예측 데이터가 생기면 보여 드려요." (데이터가 없으니 혼잡 숫자는 넣지 않는다)
- 짐 안내 카드 1개: "짐은 방문자센터에 맡겨요." / "6시에 닫아요."
- 아래 버튼 2개: '다른 전시로 바꾸기' · '길 안내 보기'

[화면 2-1 — 시간이 모자랄 때]
- 화면 2와 같은 틀, 맨 위 주황 띠: "시간이 짧아요. 전시 하나만 골라요."
- 전시 A · 전시 B 카드를 나란히 두고 하나를 누르게 한다

[화면 3 — 길 안내]
- 제목: "처음이면 길부터 알려 드려요."
- 번호·화살표 4단계: 문화전당역 → ACC 입구 → 하늘마당 옆 에스컬레이터 → 전시장
- 출구 번호 자리: "역 안내도에서 확인해요." + '확인 필요'
- 맨 아래 '코스로 돌아가기' 버튼

[화면 4 — 나갈 시간 알림 + 다음 갈 곳]
- 위에서 내려오는 알림 카드: "30분 뒤에 나가요."
- 가로로 넘기는 카드 3장: 동네 A · 동네 B · 동네 C
  - 카드마다 이름, 한 줄 소개 "후기가 있어요", 이동 시간 '확인 필요'
- 맨 아래 '여기로 갈게요' 버튼

[화면 5 — 운영자 화면]
- 맨 위: 기준 날짜 자리 + "예측값이에요" 한 줄
- 2×2 카드: 전시별 혼잡 / 전시별 관람 수요 / 외지 방문객 비율 / 근방 이동 비율
- 4개 모두 지금은 값이 없으니 흐린 남색으로 "데이터 필요"

[마지막으로]
- 다 만든 뒤 모든 화면 문구를 하나씩 세어 40자 넘는 문장, 느낌표, "~습니다", 관람료가 있는지 스스로 점검해 고친다.
- 점검 결과를 표(문구 / 글자 수 / 규칙 통과)로 같이 보여 준다.
```

## 프롬프트를 이렇게 짠 이유
| 넣은 것 | 근거 |
|---|---|
| 화면 5장 + 시간 부족 상태 1장 | 팀 기획서 "화면 시안 요청문" 화면 1~5, 화면 2의 "시간이 모자랄 때" 상태 |
| 색 3가지·글씨 크기·버튼 높이 | 팀 기획서 "공통 규칙" 그대로 |
| 해요체·40자·쓰지 않는 말·5·18 재촉 금지 | 팀 `brand/brand-skill.md`, `박대식/brand/my-brand-skill.md` |
| 확인된 숫자만 (10~18시, 수·토 20시, 월요일, 24분, 짐 6시) | ACC 공식 누리집·광주교통공사 (2026-11-19 박대식 확인, `박대식/brand/my-brand-skill.md`) |
| 혼잡 숫자 대신 "예측 데이터가 생기면 보여 드려요." | 팀 기획서 서비스 8번 — 예측 데이터가 생긴 뒤에만 보여 줌. 지금은 데이터 필요 |
| 운영자 카드 4개 모두 "데이터 필요" | 팀 기획서 "운영자에게 알려 줄 예측값" — 4개 모두 데이터 필요 상태 |
| 결과물을 HTML로 | 누르면 넘어가는 시안을 바로 열어 볼 수 있게 (제안 — 그림 한 장으로 받고 싶으면 [결과물]을 "그림 6장"으로 바꾼다) |
| 마지막 자기 점검 | 팀 기획서 성공 기준 "미확인 정보를 단정한 문장 0건" |

## 받은 시안 점검표
- [ ] 화면 6장(1, 2, 2-1, 3, 4, 5)이 모두 있다
- [ ] 색이 남색·크림·주황 3가지뿐이다
- [ ] 시간 숫자가 가장 크다
- [ ] 입력은 남은 시간·동행 2개뿐이다
- [ ] 해요체만, 40자 이하, 느낌표·이모지 없음
- [ ] 관람료·실제 전시 이름·가게 이름·사진이 없다
- [ ] 확인 안 된 시간(걷는 시간·출구 번호·동네 이동 시간) 옆에 '확인 필요'가 있다
- [ ] 혼잡 숫자를 지어내지 않았다
- [ ] 5·18 공간에 재촉하는 말이 없다

## 확인 필요
- 동료 캐릭터(짐꾼 등, 광주 사투리)는 팀 기획서에 없어서 넣지 않았다 (`박대식/brand/my-world-bible.md`에만 있음)
- 시안에 쓸 도구(Claude HTML / 그림 생성 AI / 피그마)는 정하지 않았다 — 지금은 HTML로 제안
