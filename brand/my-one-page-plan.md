| 이름 | 기차 시간 맞춤 ACC 코스 (가제) — "몇 시 기차예요?" |
| 타겟 고객 | 광주 밖에서 와서 여행·행사 일정 중에 ACC에 들르는 방문객 (팀 타깃 B) |
| 문제 | 정선아 리뷰 87건 중 타지 방문 9건. 그중 **4건은 행사·다른 여행 사이에 끼워 넣은 방문**(B6·B10 비엔날레, B32 완도 가는 길, B49 공연), **3건은 광주 여행 코스 중**(N7, B5, B24). 이런 방문객이 겪은 불편: 시간·마감 2건(신희연 B30 일정 맞추기 어려움, B84 6시 마감 아쉬움 — 팀 `brand/persona_Detail.md` 기준), 길 찾기 2건(신희연 B78, 정선아 B45), 혼잡 2건(정선아 N7, B37). 송정역에서 30분 더 걸린다는 말도 있음(영상 talk-show, 광고 영상) |
| 서비스가 하는 일 | 돌아가는 기차 시간과 동행(혼자·친구·아이와)을 고르면, **남은 시간 안에 볼 전시 1~2개 → 길 → 짐 → 다음 역(동명동·양림동)**을 시간 순서대로 짜 준다. 시간이 모자라면 "다 못 봐요"라고 말하고 하나를 고르게 한다. 붐빌 것 같은 시간은 예측이라고 밝히고 미리 보여 준다. 운영시간은 ACC 공식 정보만 쓰고, 관람료는 넣지 않는다. 짐 보관·입장 마감·이동 시간처럼 확인 안 된 정보는 "~라고 해요. 확인해요."로 안내한다 |
| 운영자에게 알려 줄 예측값 | ① 요일·시간대별 전시장 혼잡 — **데이터 필요** (공공데이터포털은 연도·시설별 방문객 수만 있음) ② 행사 기간(비엔날레 등) 타지 방문 증가 — **데이터 필요** (지금은 리뷰 수만 있음) ③ 기차 시간 때문에 놓친 전시(입력 시간 대비 추천 못 한 전시) — **데이터 필요** (서비스를 쓰면 쌓임). ※ 혼잡 예측(①)은 운영자와 **방문객 모두에게 공개**한다. 방문객에게는 "예측이에요"라고 밝힌다 (`my-brand-skill.md`, 2026-11-19 박대식 결정). 예측 데이터가 생기기 전에는 보여 주지 않는다 |
| AI가 하는 일 | 입력한 시간·동행으로 코스를 계산하고, 추천 이유를 역무원 말투 한 문장으로 설명한다. 문구를 쓸 때 `my-brand-skill.md`를 먼저 읽는다 — 해요체, 한 문장 40자·정보 하나, 확인된 숫자만, 느낌표·이모지 없음, 쓰지 않는 말 금지. 확인 안 된 정보(마감·짐 보관·이동 시간·도슨트 시간)는 단정하지 않고 "확인해요"로 표시한다 |
| 성공 기준 | 시범 사용자(광주 밖 방문객) 5명 중 4명이 "기차 시간 안에 계획대로 다녀왔다"고 답한다 (가정) / 5명 중 4명이 추천 이유를 이해했다고 답한다 (가정) |

## 근거 메모
- 타지 방문 9건 분류: `박대식/리뷰고객분석.md` 3번 표 ③ (N6은 ACC가 목적, B30은 방문 계기 불명확이라 위 분류에서 뺌)
- 실제 방문객 거주지: 광주 약 69%, 서울 11%, 전남 10%대 (`아시아문화전당조사.md` 7번) → 타깃 B는 약 3할
- 한 전시 설문 응답자의 51%가 타지역 (영상 `조민식/archive/video-acc-asia-devices-visitors.md`, 한 전시 결과라 전체 비율 아님)
- 신희연 B 번호는 정선아 B 번호와 다른 글
- ACC 공식 개관시간 (2026-11-19 확인, https://www.acc.go.kr/main/contents.do?PID=060101): 내부시설 10~18시, 문화정보원·문화창조원 수·토 20시까지, 외부시설 6~22시, 휴관 매주 월요일·1월 1일, 일정에 따라 바뀔 수 있음

> 모바일 앱 첫 화면 시안을 그림 한 장으로 그려줘.
