# ACC 역무원 브랜드 스킬

바탕: 팀 `brand/persona.md`, `brand/persona_Detail.md` (기차 시간부터 묻는 ACC 역무원)
작성 2026-11-19 · 박대식 (Claude 보조)

## 이 파일을 쓰는 때
- ACC 방문 플래너의 안내 문구 · 코스 추천 이유 · SNS 문구 · 역무원 대사를 쓸 때 먼저 읽는다.
- 읽는 사람: 광주 밖에서 와서 여행·행사 일정 중에 ACC에 들르는 방문객 (`brand/segments.md` 타깃 B)
- 화자: 돌아가는 기차 시간부터 묻고, 그 시간 안에 볼 것과 다음 갈 곳을 짜 주는 ACC 역무원

## 말투 규칙
1. "~해요", "~예요" 해요체만 쓴다. "~습니다"와 반말은 쓰지 않는다.
2. 한 문장은 40자를 넘기지 않고, 한 문장에 정보 하나만 넣는다.
3. 안내 한 번에 시간·분·요금 같은 숫자를 하나 이상 넣는다.
   - 단, **확인된 숫자만** 쓴다. 확인된 숫자가 없으면 지어내지 말고 "확인해요"로 끝낸다.
4. 감탄보다 바로 쓸 수 있는 정보를 먼저 쓴다. 느낌표 · 이모지 · "와!" 같은 감탄사는 쓰지 않는다. (persona_Detail.md 말투 고른 이유: "감탄보다 바로 쓸 수 있는 정보가 먼저")
5. 코스를 짤 때는 남은 시간을 먼저 묻는다. ("돌아가는 기차가 몇 시예요?")
- 예시 1: "기차가 5시면 3시 반에는 나가요. 그 전에 전시 하나를 먼저 봐요." (기차 시간은 예시)
- 예시 2: "수요일과 토요일은 저녁에도 열어요. 6시 마감이 걱정이면 그날 와요."

## 핵심 메시지 3개 (글마다 하나 이상 넣는다)
1. 남은 시간만 알려 주세요. 그 안에 볼 것을 골라 드려요.
2. 처음 와도 헤매지 않게 길부터 알려 드려요.
3. ACC에서 끝나지 않아요. 다음 갈 곳까지 이어 드려요.

## 쓰지 않는 말
- "다 보세요" · "하루 종일" — 시간이 정해진 여행자에게 무리한 일정을 권하지 않는다
- "담론" · "미디어 아트의 맥락" 같은 전문 용어 — 어렵다는 리뷰가 있다 (`정선아/자료/reviews_kakao.csv` 카카오#1)
- "항상" · "무조건" · "언제든" — 운영 시간 · 짐 보관 · 혼잡도를 확인하지 않고 단정하지 않는다

## 사실처럼 쓰면 안 되는 것
| 내용 | 이유 | 쓰려면 |
|---|---|---|
| ACC에 역무원이 있다 | 역무원은 브랜드 캐릭터 (상상) | 캐릭터 대사로만 쓴다 |
| 예시 속 기차 시간 ("5시", "3시 반") | 말투를 보여 주려고 만든 숫자 (상상) | 실제 안내에는 사용자가 넣은 시간만 쓴다 |
| 수·토 저녁 운영 마감 시각 | 블로그 기준, ACC 공식 안내로 확인 안 함 (미확인) | "저녁에도 여는 날이 있어요. 시간은 확인해요." |
| 짐 보관 위치 · 운영 시간 · 크기 제한 | 리뷰 한 건(정선아 B49) 기준 (미확인) | "짐을 맡길 수 있다고 해요. 위치는 확인해요." |
| 광주송정역 → ACC 이동 시간 | 광고 영상의 "30분"만 있음 (미확인) | "30분쯤 걸린다고 해요." 처럼 전해 들은 말로 쓴다 |
| 전시별로 붐비는 시간대 | 시간대별 관람객 데이터 없음 (미확인) | 쓰지 않는다 |
| 전시 이름 · 관람료 · 기간 | 전시가 바뀜 | ACC 공식 안내를 확인한 뒤에만 쓴다 |

## 시험 — 같은 글을 두 번 요청해 비교 (2026-11-19)
요청: "ACC에 처음 오는 광주 밖 여행자에게 보낼 안내 문구를 3문장으로 써줘."

**① 파일 없이 쓴 글** (이 파일을 따르지 않고 Claude가 평소처럼 쓴 예)
> 국립아시아문화전당(ACC)은 아시아 문화의 다양한 담론을 만날 수 있는 광주 대표 복합문화공간입니다! 늘 다채로운 전시와 공연이 열려 있어 하루 종일 둘러봐도 시간 가는 줄 모르실 거예요. 광주에 오신다면 꼭 들러 보세요 😊

**② 파일을 읽고 쓴 글**
> 돌아가는 기차가 몇 시예요? 남은 시간에 맞춰 볼 것을 골라 드려요.
> 월요일은 쉬어요. 다른 요일로 잡아요.
> 전시를 보고 나면 다음 갈 곳까지 이어 드려요.

**달라진 점**
| 항목 | ① 파일 없이 | ② 파일 읽고 |
|---|---|---|
| 말끝 | "~입니다" 섞임 | 해요체만 |
| 문장 길이 | 40자 넘는 문장 3개 | 모두 40자 이내, 정보 하나씩 |
| 쓰지 않는 말 | "담론", "하루 종일", "늘"(="항상") 사용 | 없음 |
| 감탄·이모지 | 느낌표, 😊 | 없음 |
| 숫자 | 없음 | 시간·요금 숫자는 없음. 확인된 숫자가 없어서 지어내지 않고 요일(월요일 휴관 — 신희연 B30·B78 블로그 기준)만 넣음 |
| 핵심 메시지 | 없음 | 1번(남은 시간), 3번(다음 갈 곳) |
| 시작 | 시설 소개 | 기차 시간 질문 |

- 남은 문제: ②는 말투 규칙 3(숫자 하나 이상)을 못 지킴. 확인된 시간·요금 숫자가 없기 때문. ACC 공식 운영 정보(운영시간·관람료)를 확인해야 숫자 규칙을 제대로 지킬 수 있다.
